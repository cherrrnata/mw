Project overview

Ozon Rocket was a logistics startup running inside Russia’s largest e-commerce infrastructure. It served B2B clients shipping parcels through Ozon’s 19,000+ pickup point network at ~2M parcels/day. As Senior Product Designer, I owned the client-facing web application, its admin panel, and led the UX side of a full website redesign.

Problem

Ozon Rocket wanted to become Russia’s leading logistics operator — but the website was leaking clients at the very first step. Fewer than 3% of users finished registration, and the ones who did flooded the support center with questions. The site wasn’t explaining how the service worked or how to start using it.

Our solution

Website redesign

I led the UX side of a full website redesign aimed at turning visitors into registered clients. The work ran end to end: user research to find where people got stuck, wireframes to test structure fast, usability testing to validate, and a final review pass with the UI and front-end teams to ship it right.

Process

User research. I interviewed 7 potential clients, asking things like “Is it clear how much delivery will cost?” and “Do you know how to start?” The key insight: easy integration through APIs and CMS was the deciding factor for switching services — and its absence was the main barrier. So I designed a dedicated page with step-by-step integration instructions.

Prototype. I built low-fidelity wireframes and shared them with Product, Marketing, Engineering, and users — a fast way to test structure and flow before investing in high-fidelity design. It let me experiment and catch usability issues early. Validating the designs. As part of the UX team, I ran usability testing with primary users, watching how they moved through the prototype. Navigation and finding key information got noticeably easier.

Finishing layouts. I reviewed the UI team’s high-fidelity work against user goals, specified missing interactions with the front-end team, and ran a UX review on every implemented ticket before it went live.

Impact

The redesigned site gave clients a clear path from landing to registration, with integration instructions that removed the biggest barrier to switching. Beyond the website, I shipped a new admin panel for account management, rolled Ozon’s unified design system into the app, and helped onboard the mobile designer — leaving the product more consistent and easier to build on than I found it.
